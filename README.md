# MiniCraft на Python

Небольшая 3D-песочница в духе Minecraft. Мир из блоков, холмы, деревья,
управление от первого лица и свободное строительство. Это самостоятельный
учебный проект: текстуры генерируются программно, оригинальные ресурсы Minecraft
не используются.

## Запуск

Рекомендуется **Python 3.12**; зависимости поддерживают Python **3.12–3.14**.
Для Python 3.15 у Panda3D пока нет готового пакета для Windows.
Также нужны экран и графический драйвер с поддержкой OpenGL.
Откройте терминал в папке проекта.

**Быстрый запуск с uv (Windows / Linux / macOS):**

Если установлен [uv](https://docs.astral.sh/uv/getting-started/installation/),
выполните:

```powershell
uv run --python 3.12 --with-requirements requirements.txt main.py
```

uv выберет Python 3.12, при необходимости скачает его, установит зависимости
в отдельное окружение и запустит игру. В Windows можно просто открыть
`start.bat` двойным щелчком. При первом запуске нужен доступ к Интернету.

**Windows без uv (с установленным Python 3.12):**

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

**Linux / macOS:**

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

В подготовленном облачном окружении зависимости уже установлены в `.venv`.
Для обычной игры нужен компьютер с экраном. Облачная проверка ниже работает
без экрана и не открывает игровое окно.

### Ошибка `No module named 'panda3d'`

Игра запущена интерпретатором, в котором не установлены зависимости. Используйте
команду с uv выше либо установите `requirements.txt` в `.venv` и запускайте
именно `.venv\Scripts\python main.py` в Windows. В VS Code выберите этот же
интерпретатор через **Python: Select Interpreter**. Запуск системным Python 3.15
не использует зависимости, установленные в другом окружении.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD и мышь | Двигаться и смотреть |
| Пробел | Прыгнуть |
| Shift | Бежать |
| Левая кнопка мыши | Сломать блок |
| Правая кнопка мыши | Поставить блок |
| Средняя кнопка мыши | Выбрать блок под прицелом |
| 1–7 или колесо мыши | Выбрать материал |
| F5 | Сохранить мир |
| Esc | Пауза, сохранение и выход |

Материалы: трава, земля, камень, песок, дерево, листва и кирпич.
Блоки доступны без ограничений. Дальность строительства — 6 блоков.
Нижний слой нельзя сломать; поставить блок внутрь игрока нельзя.
При падении за край мира игрок возвращается к точке появления.

## Мир и сохранения

Мир размером **48 × 48** блоков; строить можно до высоты **64**.
Для скорости видимые грани объединяются в чанки, после изменения блока
перестраиваются только затронутые чанки.

Сохранение находится в `saves/world.json` и загружается при следующем запуске.
Сохраняются изменённые блоки, позиция игрока, направление взгляда и выбранный
материал. Автосохранение выполняется каждые 30 секунд, при открытии паузы
и при обычном выходе. Принудительное завершение процесса может потерять изменения
после последнего сохранения.

Создать отдельный мир с другим начальным числом:

```bash
.venv/bin/python main.py --seed 123 --save saves/second-world.json
```

`--seed` используется только для нового мира. Повреждённое сохранение не
перезаписывается: игра сообщает об ошибке. Укажите другой путь через `--save`
или сохраните резервную копию проблемного файла перед исправлением.

## Проверка

Тесты логики мира не требуют установки Ursina:

```bash
python -m unittest discover -s tests -v
```

Проверка настоящей 3D-сцены с программным рендерером без окна:

```bash
.venv/bin/python main.py --smoke-test --screenshot screenshots/smoke.png
```

Она проверяет рендеринг, коллизии после установки и удаления блока,
ходьбу, прыжки, бег, выбор материала, паузу и сохранение/загрузку.
Проверка использует EGL без окна с запасным программным рендерером;
захват физической мыши в этом режиме не проверяется. Пользовательское сохранение
при этой проверке не читается и не изменяется.

В этой версии нет крафта, мобов, режима выживания, бесконечной генерации
или сетевой игры.
